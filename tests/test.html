Downloads

Files go where Chrome puts them for you, usually ~/Downloads, numbered when a name repeats. The bar shows progress while one runs. Links to other sites need the network.

  • A small text file (click twice: the second is numbered)
  • (a script builds it, then downloads it as made-here.csv)
  • A file the server names (a checksum from kb's release)
  • In a new tab (a download the link opens in a new tab, which closes itself)
  • A 1 MB archive (kb's release)
  • A slow 1 MB file (about 10 seconds; quit kb during it and nothing is left behind)
  • A name set by a header (named-by-header.txt)
  • kb's logo, which opens instead (a download attribute on another site's file is ignored, as in Chrome)
